Calibrated

Draw the number. Don't describe it. Calibrated sets a count, a position, progress, a size or a duration as a small technical figure, built from eight marks.

Pure CSS + vanilla JSNo build stepLight and darkClaude Code skillsMIT

In use on lirah.dev.

Installation #

/plugin marketplace add emdmed/calibrated
/plugin install calibrated@calibrated

The skills show up as calibrated:calibrated-tokens, calibrated:calibrated-figures and so on.

git clone https://github.com/emdmed/calibrated
cp -r calibrated/skills/* ~/.claude/skills/

Copy into ~/.claude/skills/ for every project, or into .claude/skills/ for one.

The rules #

  • A figure replaces text the UI already shows, from data it already has.
  • Eight marks only, one scale per figure, numbers at the major ticks. Values go in boxes on leaders.
  • Ink in quiet hairlines on panels. The lamp marks the one live thing with an amber line, text or star; red marks faults and limits; green marks what passed. Hatch means you can't.
  • Full form prints the scale and boxes; compact keeps only the marks.
  • Leave terminals, prompts and menus alone.

The eight marks

Every figure in the kit is built from these. They are plain functions on Calibrated.K that return SVG strings.

Instruments

Custom elements. Each draws an SVG with a title and an aria-label that states its facts in words. All accept density="full|compact", or follow the nearest [data-density].

Meter #

A value against its limit, with a red-hatched alert zone and a boxed reading. It sweeps to its value when it comes into view and glides when the value changes: the needle leads, the fill follows, and the reading blinks when it settles.

AttributeDefaultDescription
value, max0, 100The reading and the full scale.
warn0.8 × maxStart of the alert zone. The part of the fill past it turns red, and so does the reading.
labelvalueName in the box and in the spoken sentence.
formatkk (46k, 1M), raw, pct or dur.
unitnoneAppended after k and raw values.
width420 / 144Full and compact widths.
stilloffNo motion: draw the value at once. Reduced motion does the same.

Position #

Where you are in a set. Up to 24 items get one tick each; longer sets get a scale with a marker.

AttributeDefaultDescription
index1Current item, 1-based.
count1Number of items.
labelnoneShown above in full form.
widthautoFor long sets.

Progress #

Steps as nodes: done, live, to do and failed, with the finished run dimensioned.

AttributeDefaultDescription
done, total0, 1Finished steps and step count.
live, faultnone1-based index of the running or failed step.
statesnoneOr list every step: done,done,live,todo,fault.
live-labelnoneHighlighted caption under the live node.
fault-labelneeds youCaption under the failed node.
done-labelnoneA dimension line over the finished run.
step18Spacing between nodes.

Diff #

Added lines run right in green, removed lines left in red, from a shared centre. Linear up to the knee, logarithmic past it. Stacked diffs share the centre line.

AttributeDefaultDescription
added, removed0Line counts.
labelnoneName at the left.
knee, max200, 100000Where the scale turns logarithmic, and its end.
name-width64Room for the label.

Durations #

Spans on one shared ruler. A live span with a start time ticks every second.

AttributeDefaultDescription
maxautoOn <cal-durations>. Rounded up to 5.
unitms, m or h.
width480Ruler width.
namenoneOn <cal-span>.
valuenoneSeconds. Or give start and end in epoch ms.
liveoffLights the span with the lamp and ends it in a live star.

Ruler #

A scale on its own, with an optional marked value.

AttributeDefaultDescription
min, max, step0, 100, 10Range and tick spacing.
every5Number every nth tick.
unit, widthnone, autoLabel suffix and drawn width.
upoffLabels above the line.
valuenoneA lamp marker.

Figures

Recipes take data and return a whole figure as an SVG string. Mount it into an empty <svg> with Calibrated.mount(), or use Calibrated.play(svg, recipe, data) to replay it when it comes into view (lanes, budget, merge, fan-out, loop and measured move). Example data on this page is illustrative.

Lanes #

Runs on one time ruler; the live one is lit by the lamp.

Budget #

A limit, its alerts, and today's pace to the end of the period.

Merge #

A branch with the exact command at each node.

Fan-out #

One parent; live and finished children.

Loop #

Stations on a cycle with what each one runs.

Measured #

A long scale, a detail at 20:1, and boxed parts.

Timeline #

Consecutive steps; the slowest is called out.

Matrix #

Which releases touch which services.

Section #

Nested regions: hatched is closed, clear is open.

Components

Pure CSS classes, plus a little JS for counts and sign-off. They carry the kit's drawing-sheet look into your own pages.

Card and sign-off #

A proposed figure beside the text it replaces, with keep and drop buttons. The tally counts the sign-offs and copies them.

Counts #

A zero-padded number in a box with its noun. Calibrated.counts() fills them from data-n.

Tabs #

Ruled tabs with boxed counts.

Buttons #

A bracketed word. Primary is in ink and lights the lamp on hover; quiet is an underline.

Marks in text #

Status dots, revision triangles and the lamp, used inside running text.

Form #

Write-in lines with caps labels, hints and errors.

Rows #

A list with a selected row.

Table #

A parts list. Instruments fit in cells in compact form.

Title block #

The ruled grid of terms and values from the corner of a drawing. Set the column count with --tb-cols.

Revisions #

Red triangles paired with what changed.

When to draw #

A two-column note for deciding what gets a figure.

Theming

Two themes, film and night, set with data-theme. The theme button at the top switches both the docs and every preview.

Seeds #

Three colours; every surface, line and wash derives from them with color-mix(). Changing a seed here re-colours every preview on the page.

Density #

Full form prints scales, boxes and labels. Compact keeps only the marks, for tables and tight rows.
