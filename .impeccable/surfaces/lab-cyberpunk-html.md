# Lab: cyberpunk courier dispatch

Scope: lab/cyberpunk.html, a lab example that re-seeds Calibrated into a cyberpunk world. Mode: Operate.
Audience: a dispatcher watching one live courier run. Task: read where the run is, whether it will make the window, what the cargo is, and confirm or abort the next jump.
Constraints: kit loaded live from skills/*/assets; seeds only for colour; original city and district names (no game IP); illustrative data labelled.

## Direction contract

THESIS: A dispatch board where the route is a measured drawing, not a map pin. Refuses the dashboard-of-stat-tiles default.
OWN-WORLD: Calibrated panels on a violet-black desk; cyan lamp tube for the one live leg, magenta markup for faults, acid green for passed; hairlines crisp, only lamp strokes glow; corner registration marks; faint scanlines.
STORY: The dispatcher sees the run, sees it is 2 min behind pace, checks cargo temperature, confirms the next jump.
FIRST VIEWPORT: Masthead with run id and clock; full-width route figure (lanes on a time ruler, live leg lit); below, ETA budget with pace and cargo sheet side by side; jump confirm bar with primary CONFIRM JUMP.
FORM: Courier dispatch, list position 5, seed 67c0580b.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
